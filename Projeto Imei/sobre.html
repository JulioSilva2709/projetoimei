Sobre a CheckPoint

A CheckPoint é uma loja online dedicada ao mundo dos videojogos e dos computadores. No nosso site é possível encontrar jogos, periféricos e componentes de PC no mesmo lugar.

O nosso objetivo é facilitar a compra de produtos para jogadores e utilizadores de computador, oferecendo várias opções, desde jogos digitais até equipamentos para melhorar o computador e a experiência de jogo.

O que podes encontrar

Na CheckPoint podes encontrar diferentes tipos de produtos, como:

  • Jogos
  • Periféricos
  • Auscultadores e microfones
  • Controles
  • Componentes de computadores
  • Outros componentes e acessórios para PC

O nome CheckPoint

O nome CheckPoint foi inspirado nos checkpoints dos videojogos. Um checkpoint representa um ponto de progresso no jogo, onde o jogador pode continuar a partir daquele momento.

Escolhemos este nome porque queremos que a CheckPoint seja um ponto de referência para quem procura produtos relacionados com gaming e computadores.

O nosso objetivo

Queremos juntar vários tipos de produtos numa só loja, tornando mais fácil encontrar tudo o que é necessário para jogar, melhorar ou montar um computador.
